# MyCluster · web

- `index.html`: explorador público con mapa OpenStreetMap, sin iniciar sesión, sin datos familiares y sin SOS operativo.
- `app.html`: aplicación React real procedente del build del repositorio privado `Momentumsystems1/cluster`. Requiere una cuenta Supabase y pertenecer a un círculo para acceder al mapa de miembros.
- `assets/`: JS y CSS del build original. `logo.png`: recurso original.

Acceso público: https://momentumsystems1.github.io/mycluster/

No se han modificado ni la autenticación ni las políticas de seguridad del backend.
