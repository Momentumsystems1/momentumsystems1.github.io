# MyCluster — publicación web

Origen: repositorio privado `Momentumsystems1/cluster`, carpeta `dist/` (build Vite/React).

Esta carpeta es una publicación independiente de MyCluster en GitHub Pages. No modifica BRIGADA 3, BAYMOVE, ORBEOS ni otras aplicaciones del sitio principal.

El inicio y la interfaz cargan estáticamente; autenticación, datos familiares, localización compartida, SOS, invitaciones y mapas dependen de los servicios externos autorizados y de los permisos del navegador.

Última sincronización del build: 27-10-2026. Para cambios funcionales, modificar y construir el repositorio `cluster`, no este bundle.
