# Momentum Systems — Web

Sitio web estático (HTML/CSS/JS, sin backend).

## Estructura
- `index.html`, `calidad.html`, `flotas.html`, `gobernanza.html`, `my-cluster.html`, `v16.html` — páginas principales
- `legal/` — aviso legal, privacidad, cookies, accesibilidad
- `app/` — privacidad, términos, soporte, eliminación de cuenta
- `assets/` — CSS, JS, imágenes, vídeos y fuentes
